Leonida Legend — an offline static web app tracking all 55 official GTA 6 trophies, each with a guide in its maker's own words and cited sources, a roadmap to platinum, missable trophies flagged, a checklist saved in the browser with export/import, filters by kind, and a spoiler setting that hides story trophies until earned. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
